# init-wc-lab

## 项目简介

init-wc-lab 是一个用于归档和发布独立 HTML 页面的仓库。本仓库不针对任何特定域名或网站，仅作为静态页面的存储与展示空间。仓库中的 HTML 文件均为独立完整页面，不依赖外部资源，可直接在浏览器中打开使用。

## 目录说明

```
├── README.md          # 本文件
├── pages/             # 存放所有 HTML 页面文件
│   ├── example1.html  # 示例页面（可删除或替换）
│   └── ...
└── assets/            # 可选：存放页面引用的公共资源（如样式、图片等）
    └── ...
```

- **pages/**：所有独立 HTML 页面均放置在此目录下，每个页面为一个独立的 .html 文件。
- **assets/**：如果页面需要引用公共资源（如 CSS、JS、图片等），可在此目录下创建子目录存放。建议每个页面尽量自包含，减少外部依赖。

## 页面归档说明

- 每个 HTML 页面应为完整、自包含的文档，包含 `<!DOCTYPE html>` 声明、`<html>`、`<head>` 和 `<body>` 等基本结构。
- 页面标题（`<title>`）建议明确描述页面内容或功能，便于识别。
- 页面之间相互独立，不互相依赖。
- 如果页面使用了外部资源（如字体、图标库），请在页面内部引用（如 CDN 链接），但注意长期可访问性。

## 维护说明

- 本仓库采用 Git 进行版本管理，每次提交应包含清晰的提交信息，描述新增或修改的页面内容。
- 新增页面时，请在 `pages/` 目录下创建新的 .html 文件，并确保文件命名简洁、不含特殊字符。
- 删除或修改已有页面时，请确认无其他页面依赖该文件。
- 不建议在仓库中存放敏感信息或私密内容，因为公开仓库中的文件可被任何人访问。
- 如果页面需要长期维护，建议定期检查外部资源的可用性。
